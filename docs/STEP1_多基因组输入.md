# ============================================================
# Step 1 技术文档: 多基因组输入
# ============================================================

## 概述

Step 1 是 LINC 框架的数据输入阶段,负责从文件系统中读取多个基因组的蛋白编码基因序列。

---

## 输入

- **格式**: FASTA 文件 (`.faa` / `.fa` / `.fasta`)
- **数据来源**: 用户通过 YAML 配置文件指定

---

## 关键设计决策

### 1. 基因组级增量而非序列级增量

**为什么选择基因组作为基本单位?**

| 特性 | 基因组级增量 | 序列级增量 |
|------|-------------|-----------|
| 生物学依据 | 原核生物单基因组内,绝大多数基因家族为单拷贝或寡拷贝 | - |
| 工程便利 | 基因组边界天然清晰 | 需要额外分组信息 |
| 计算开销 | 每个基因组只处理一次 | 逐条序列重复访问代表库 |
| 并行化 | 无需额外同步 | 需要处理依赖关系 |

### 2. 路径解析策略

配置文件在 `config/` 目录,数据在 `data/` 目录:
- 配置文件的路径解析基于**项目根目录** (config 的上一级)
- 确保相对路径 `data/genome01.faa` 能正确解析

## 输出数据结构

### GenomeInfo

```python
@dataclass
class GenomeInfo:
    genome_id: str           # 基因组唯一标识符
    file_path: str          # FASTA 文件绝对路径
    n_sequences: int       # 蛋白编码基因数量
    total_length: int       # 序列总长度
    avg_length: float       # 平均序列长度
    min_length: int         # 最短序列长度
    max_length: int         # 最长序列长度
    status: str            # pending / loaded / failed
```
