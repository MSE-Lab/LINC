## 快速导航

### Step 1: 多基因组输入

**功能**: 从 FASTA 文件读取基因组序列

```
输入: config.yaml → genome_list: ["data/genome01.faa", ...]
输出: Dict[genome_id, GenomeInfo]
```

**关键概念**:
- 基因组级增量 vs 序列级增量
- 路径解析策略

---

### Step 2: 基因组内自聚类

**功能**: 每个基因组独立执行全对全比对,提取局部代表

```
输入: GenomeInfo (3 个基因组, 20 个基因)
处理: All-vs-All 比对 → Union-Find 聚类 → 代表提取
输出: Dict[genome_id, GenomeIntraResult] (9 个局部簇, 9 个代表)
```

**关键概念**:
- 全对全比对 vs 增量聚类
- 孤儿基因 (ORFans) 处理
- 代表选取策略

---

### Step 3: 增量并入全局代表库 (核心)

**功能**: 将各基因组局部代表增量并入全局代表库

```
输入: GenomeIntraResult (9 个局部代表)
处理: Order-D 排序 → 双阈值判定 → 多代表决策树
输出: IncrementalResult (9 个全局簇, 9 个代表)
```

**关键概念**:
- Order-D 确定性排序
- Cutoff-I / Cutoff-II 双阈值解耦
- 三条决策路径 (0簇/1簇/≥2簇命中)
- 一次比对,全局复用

---

### Step 4: 稀疏 SSN 构建

**功能**: 基于增量结果构建稀疏序列相似性网络

```
输入: IncrementalResult
处理: 代表-代表边添加 → 节点添加 → 连通分量分析
输出: SparseSSN (9 节点, 0 边, 9 连通分量)
```

**关键概念**:
- 稀疏 SSN vs 完整 SSN
- NetworkX 图结构
- 连通分量分析

---

### Step 5: 最终补边

**功能**: 补全 SSN 边集合,保证数学等价性

```
输入: SparseSSN + IncrementalResult
处理: 识别待补边对 → 剪枝 → 批量比对
输出: CompleteSSN (完整边集合)
```

**关键概念**:
- 延迟补边策略
- 数学等价性证明
- 长度预过滤
- compared_pairs 去重

---

### Step 6: MCL 亚家族细分

**功能**: 在 SSN 连通分量上运行 MCL,细粒度聚类

```
输入: CompleteSSN
处理: Inflation 参数选择 → MCL 聚类
输出: MCLResult (直系同源家族列表)
```

**关键概念**:
- Markov Cluster Algorithm
- Inflation 参数
- 从超家族到直系同源家族

## 核心创新点

### 1. 双阈值解耦

```
Cutoff-I (纳入阈值) ────────────► 决定是否成簇
Cutoff-II (高置信阈值) ─────────► 决定是否新增代表

两者是语义完全不同的两种生物学判定,
不是"宽松/严格"的参数选择。
```

### 2. Order-D 确定性排序

```
优先级1: 基因组基因总数 ↓  (大基因组优先)
优先级2: 局部代表数 ↓     (高多样性优先)
优先级3: 文件名字典序 ↑    (兜底唯一)

消除输入顺序随机性,保证结果可复现。
```

### 3. 增量架构三件套

| 机制 | 作用 |
|------|------|
| 代表压缩 | 搜索空间从 N² 降至 M² |
| 增量演进 | 每步只比新-全局 |
| 延迟补边 | 保证数学等价性 |
