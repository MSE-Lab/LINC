- [x] `multi_representative_clustering` 具体子算法已实现(2026-10-01):贪心覆盖(k-center近似),先选1个中心代表,再反复选"与已选代表集合最大相似度最低"的成员加入,直到被选代表已覆盖(某成员与已选代表相似度≥Cutoff-II)或达到 max_per_cluster 上限;配套修正了单代表/多代表判断依据(见下一条);已同步更新 `LINC_技术框架设计_v2.md`(补充 LocalCluster/GenomeIntraResult 实体定义、标注该算法对归档算法设计文档的"已知偏离"说明)
- [ ] `select_central_representative` 打分公式
- [ ] `edge_density` 计算公式
- [ ] 合并簇(`merge_clusters`)后代表集合处理规则
- [ ] `compared_pairs` 并发安全实现方式
- [ ] MCL 库选择策略(`markov-clustering` vs 系统 `mcl`)的最终 fallback 逻辑
- [ ] Checkpoint 粒度是否需要细化到基因组级别
- [x] `typer` 已引入作为新依赖(2026-10-01):用于实现 `linc run` 命令,验证 GenomeLoadStage 效果

- [x] IntraGenomeStage 单/多代表判断依据已修正(2026-10-01):v1 STEP2 文档字面写的是"最大" pairwise identity ≥ Cutoff-II 判定整体均质,但该依据在语义上不成立(仅一对高相似度成员不代表整体均质,且会导致贪心覆盖的停止条件永远无法触发,多代表分支会退化为"几乎全选"),经与用户确认改为"最小" pairwise identity ≥ Cutoff-II 判定整体均质
