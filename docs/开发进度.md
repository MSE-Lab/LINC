## 待确认/待决策事项追踪

> 汇总自 `LINC_算法设计文档.md` 第7节 + `LINC_技术框架设计_v2.md` 第7节,实现到对应模块时需优先解决:

- [ ] `multi_representative_clustering` 具体子算法
- [ ] `select_central_representative` 打分公式
- [ ] `edge_density` 计算公式
- [ ] 合并簇(`merge_clusters`)后代表集合处理规则
- [ ] `compared_pairs` 并发安全实现方式
- [ ] MCL 库选择策略(`markov-clustering` vs 系统 `mcl`)的最终 fallback 逻辑
- [ ] Checkpoint 粒度是否需要细化到基因组级别
- [ ] `typer` 是否引入作为新依赖
- [ ] `SSNEdge` 当前为非 frozen dataclass,默认不可哈希;`RepositoryPort.save_ssn_edges(edges: set)` 若未来传入真实 `SSNEdge` 实例集合会报错,需在 `SSNBuilderStage` 落地时决定是否改为 `frozen=True` 或改用其他去重 key
